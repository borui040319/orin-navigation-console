# 两个控制台的操作流程

以下按钮来自当前实际部署。新电脑只转发现有接口，不修改算法、参数、地图或控制器状态机。两个控制台都可打开预览；对机器狗下发操作时一次使用一套流程。

## 标准版与楼梯版

入口：<http://127.0.0.1:8876/>。在顶部选择 **标准版** 或 **v2 · 楼梯专用**。地图、航点和运行环境分开保存；运行中先停止任务，再切换版本。

首次建图：

1. 点击 **开始建图**，Orin 自动分配数字地图编号。
2. 等实时点云和机器人位置出现，通过遥控器采集场地。
3. 在转弯、门口等处 **记录当前位置为航点**，在目的地 **记录当前位置为目标点**，填写实际楼层。标准版 1 是连接层，普通楼层从 2 起。
4. 停止移动后点 **结束并保存地图**。楼梯版继续生成 PCT 分层地图，等状态变成可导航；失败时可用 **重新生成楼梯分层地图**。

已有地图导航：

1. 选择地图编号与附近的初始位置标记，点击 **按选定地图导航**。
2. 在三维视图检查定位与点云对齐，正确后点击 **定位正确，启动规划**。
3. 在地图或列表选择已记录的黄色目标点，点击 **前往所选目标点**。
4. 完成后用 **停止运行** 结束该程序组。

地图窗口支持旋转、平移、缩放、俯视和高度过滤；显示实时点云、机器人、航点和规划路径。实时点云只在对应流程运行并有新数据时出现，停止后可查看保存的地图。

2026-11-05 只读检查中，现有 ATEC `enable_chassis=false`，因此这页当前可以建图、定位和预览规划，目标下发不会驱动底盘。本客户端保持后端原设置，不自动开启底盘。

## CROSS

入口：<http://127.0.0.1:8888/>。此页完全由 Orin 提供，界面和方法会随 Orin 后端更新。

首次建图：

1. 选择方法，检查依赖与传感器状态。
2. 点 **开始建图**，等待里程计初始化；按现场采集流程移动机器狗／相机。
3. 记录航点或目标点，在拓扑图查看关键帧、回环、轨迹和处理帧率。
4. 点 **结束并保存地图**，等地图状态就绪。地图仍保存在 Orin，不下载到电脑。

已有地图导航：

1. 选择与地图对应的方法和地图编号，点 **按照选定地图导航**。
2. 等当前图像重定位成功，在拓扑图上选择目标节点或已记录目标。
3. 点 **规划并冻结路径**。从当前关联节点运行一次 Dijkstra，冻结路径和航点；到达一个航点只推进游标，不重新运行 Dijkstra。
4. 查看“当前附近节点 / 下一个 waypoint / 已到达 / 剩余 / 距下点”和执行状态。具备原有执行条件时，按现场操作流程使用 **执行冻结路线**。
5. **停止 Orin 速度输出** 关闭输出适配器，定位和航点更新继续；**停止导航** 才结束 CROSS 任务。

遥控接管与交还由机器狗端决定，Orin 持续定位并更新下一航点。短暂失定位时原路线与目标保留，恢复后继续；无需在新电脑上重新部署或重新点击执行来切换电脑。服务器／执行进程重启时，速度输出按现有逻辑默认关闭。

当前 CROSS 原有运动参数为前进 0.5 m/s、转向 ±0.2 rad/s、平面到达阈值 1 m。当前实现没有动态避障／局部规划器。网页展示的发送指令不是实测速度；静态测试地图不能启用实际行走。这些是现有后端的行为，不是新客户端增加的功能。

## 实时预览与共享状态

标准版／楼梯版预览三维点云、机器人位置、目标与路径；CROSS 预览拓扑图、定位、帧率、GPS 状态、冻结路线和执行状态。仓库复用现有视图，没有新增独立摄像头视频流。

新电脑、旧电脑看到同一套远端状态和地图。一个页面的停止／目标等操作会影响其他页面看到的任务。当前客户端没有另加跨电脑独占控制权；操作交接需要操作者协调。GitHub 网页仅是下载和说明入口，真正的实时预览在启动脚本后打开的两个本机页面中。
